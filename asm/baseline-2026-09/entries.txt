# IO Moon 80188 -- code entry points for the 2026-09 baseline disassembly.
#
#   <flat-address>  <CS value>  <label>          # evidence
#
# Flat addresses are 80188 physical addresses.  ROM1 ("V1 3_01.bin") is
# mapped at 0x80000-0xFFFFF, so file offset = flat - 0x80000.  <CS value> is
# the segment register value the code runs under; it is needed so that near
# branch targets resolve inside the right segment (dasmxx 'g' command).
#
# Every line here was justified from the instruction stream itself -- see
# README.md for the evidence trail.  Labels are deliberately provisional and
# describe what was observed, not what the routine is assumed to mean.
